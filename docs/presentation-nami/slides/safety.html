Keeping the bad guys out

Invite only

You only get in with a secret link. It works once, and only for 7 days.

Five tries

Guess a wrong code five times in an hour and the bot stops answering you.

Inside doors

Hackers once got into an older server through an open side door and used it to make crypto money. Now those doors only open from the inside.

True story from September: a different project's server was taken over by people mining cryptocurrency, through a port that was open to the internet. Feetness was built with that lesson: every inside service only listens on the server itself.
